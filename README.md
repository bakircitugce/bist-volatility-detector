# BIST Volatility Detector

Machine Learning based volatility prediction dashboard using Streamlit.

## Features
- Feature engineering (RSI, MACD, Bollinger Bands)
- Model comparison (LightGBM, XGBoost, CatBoost)
- Volatility prediction
- News integration

## Run locally
streamlit run app.py
